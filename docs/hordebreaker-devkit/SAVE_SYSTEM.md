# Сохранения и миграции

`js/core.js` — загрузка/нормализация, backup, запись; `js/savetools.js` — импорт/экспорт и восстановление; `js/main.js` — таймеры и visibility. localStorage: `tbh_idle_equipment_v1`, `tbh_autobackup_1..3`, `tbh_balance_backup_v55` (миграция balanceVersion 2). Автосохранение каждые 5 секунд и при важных событиях. Проверяй актуальные ключи и схему в коде.

До изменения: экспорт реального сохранения пользователем; тесты на копиях в отдельном браузерном профиле. Никогда не очищай localStorage пользователя. Не публикуй реальные save JSON.

Миграция: валидировать вход → сохранить точный исходный JSON → при отказе backup не перезаписывать → пересчитать только нужные поля → нормализовать UID/слоты/классы → сохранить прогресс → выставить версию один раз. Повторная загрузка не меняет результат. Возврат неподходящего предмета в сумку даже выше лимита, без скрытой продажи. Сохраняй XP/золото/алмазы/найм/рекорд и божественные вещи, если задача не говорит иначе. Не заменяй исходную резервную копию.

Импорт: схема, конечные числа, допустимые значения, уникальность UID, экранирование пользовательского содержимого, подтверждение и резервная копия. Проверки: balance-equipment.mjs и sanity.mjs, при UI — browser.mjs и отдельный Chrome-профиль. Укажи ограничения старого формата, не выдумывай потерянную историю.
