# Предлагаемый roadmap (не утверждённые задачи)

Порядок задаётся пользователем; это список направлений, а не обещание выполненных работ.

| Приоритет | Направление | Критерий завершения |
|---|---|---|
| P0 | Сохранность прогресса и критические регрессии | нет потерь UID/XP, миграция и тесты подтверждены |
| P1 | Боевой строй и дальники | проверены 4 дальних класса, реальный урон и переходы волн |
| P1 | Полная растровая графика | инвентаризация текущих src, остаток SVG заменён на качественные WebP; гербы сохранены |
| P1 | Баланс v55 | плейтест с реальным наймом и случайным лутом, не только контрольные симуляции |
| P2 | UI и производительность | проверены mobile/desktop, измерения до/после, нет регрессий |
| P2 | Новый контент | согласованы механика, арт, баланс и совместимость |

Не использовать старые счётчики графического прогресса из чата как текущие. Сначала измерить конфиги. Закрывать задачи только по фактическим тестам.
