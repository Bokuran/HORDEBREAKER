# Стандарт графики

Цель: детализированные живописные dark fantasy WebP, не упрощённые плоские фигуры. Эталон — удачные текущие спрайты, лесные панорамы и обновлённые предметы. SVG уместен для fallback, гербов и UI-декора; не выдавай его за новый растровый арт.

| Тип | Требования |
|---|---|
| Стандартный предмет | WebP 256×256, прозрачные края и углы, читаемый объект по центру, одна внешняя CSS-рамка редкости; без встроенных рамок/текста/подложки |
| Герой/враг/босс | отдельный WebP с альфа, цельный силуэт без соседних объектов, подписи/HP/динамическая тень рисуются движком; `face`, `region`, `full`, `pixelHeight`, `fb` сверить по коду |
| Панорама | широкая сцена с землёй для боя, отдельная тема и палитра, плавный скролл, без персонажей и UI; пропорции сверить с текущим рендерером |
| Герб карты | сохранять существующий `iconArt`; менять только по отдельной задаче |
| Divine | отдельный существующий атлас/эффект; обычные иконки не должны ломать его |

## Пайплайн
1. Выбери ID и фактический `src` из конфигов или ICONS в `js/ui.js`. Не путай наличие файла с загрузкой его игрой. Составь список оставшихся SVG по ссылкам, а не по количеству файлов.
2. Сгенерируй изолированные объекты, не макет интерфейса. При спрайт-листе — ровные ячейки, запас до краёв, единое освещение. Не используй мокап, если из него нельзя получить качественные ассеты.
3. Разрежь, удали фон/ореол, сохрани пропорции, проверь альфу и границы на светлом и тёмном фоне. WebP с разумным сжатием; не растягивай маленький кроп. Не клади промежуточные листы в assets.
4. Подключи путь/ориентацию, оставь полезный fallback, обнови версию затронутого URL и `expectedImages` в sanity при необходимости. Сохрани ID, баланс и карту.
5. Проверь реальную декодировку, прозрачность, 390/1900 px, кадр боя и инвентарь; не считать арт готовым до интеграции и проверки.

Промпт предмета: «Изолированный [предмет], dark fantasy RPG, детализированная рисованная фактура, чистый силуэт, прозрачный или однотонный легко удаляемый фон, без рамок, букв, интерфейса и подставки». Для врага добавь ракурс и полную фигуру; для фона — широкую игровую сцену без персонажей.
