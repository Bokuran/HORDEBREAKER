# Игровой дизайн — существующий контракт

Темное фэнтези, статический idle-RPG. Игрок нанимает героев, формирует отряд до четырёх, получает XP с убийств, золото и экипировку, повышает силу, проходит волны и боссов, инвестирует в Атлас, получает алмазы и обменивает на божественные вещи.

| Класс | Роль/дальность |
|---|---|
| paladin, barbarian | танки, ближний бой |
| monk, rogue | ближний DPS |
| archer, mage | дальний DPS |
| necro, druid | дальние лекари, атакуют при отсутствии нужды в лечении |

Кампания: 20 зон по 10 волн, боссы на 5/10, два местных обычных врага на зону, 40 боссов. В бою действуют пассивные и активные способности; боссы должны иметь различимые профили, а не идентичные старые наборы. После боя — пятисекундный поход, без обнуления нужных таймеров. Элитные враги по конфигу. Подробности повторов и отступлений определяет T.waves.

Экипировка: weapon, armor, talisman; 20 стандартных типов, common/uncommon/rare/epic/legendary/divine. Талисманы универсальны по классу. Класс, слот и уровень проверяются ядром. Heavy только paladin/barbarian, закалка до +5. Сумка 60 по конфигу; восстановление несовместимой экипировки может временно превысить лимит без потери предметов.

Четыре вкладки: Герои, Отряд, Инвентарь, Лагерь. Досье, сравнение, автоэкипировка, управление порядком, Атлас, обменник, сохранения. Дизайн: тёмный фон, золотые/фиолетовые акценты, читаемые состояния, без двойных рамок. Сохранения локальные, не серверные.

## Критерий нового контента
Игровая цель → доступность → правила → контент-ID → UI → графика → совместимость → тест. Не считать числа предложений утверждённым балансом. Изменение механики оформляй через шаблон FEATURE.md.
