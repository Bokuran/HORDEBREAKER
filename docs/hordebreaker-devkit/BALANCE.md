# Баланс — исходная линия v55

Источник: `config/balance.js`, `BALANCE_V55.md`, реализации в `js/core.js` и боевых модулях. Числа ниже описывают проверенный снимок репозитория, не новую настройку.

| Параметр | Значение v55 |
|---|---|
| Уровень героя | максимум 100; dmgGrowth 1.05; milestoneEvery 25, milestoneMult 2 |
| XP следующего уровня | 120 + 90 × (уровень − 1); version 2 |
| Награда XP | xpBase 18, xpWave 2; штраф слабых волн от 10% до 100% по фактической формуле |
| HP врагов | hpBase 10; growth 1.14, после 60 — 1.05, после 100 — 1.045 |
| Золото | goldBase 2, goldGrowth 1.12, goldEndgameGrowth 1.025 |

| Элита | hpMult 1.5, goldMult 1.8, waveRemainder 3 |
| Защита | defCap 60, armorConstant 250, armorWaveScale 3; пределы попадания .45/.70 |

| Дроп | шанс .10, bossChance 1, bossExtraChance .35, inventoryCap 60 |

| Офлайн | 60–14400 сек; efficiency .35, offlineItemCap 3, maxGems 4 |

Указаны имена полей, а не самостоятельные формулы: сверяй реализацию округления, интервалы, множители и начисления. Броня числовая с убывающей эффективностью. Обычный лут следует ожидаемому уровню волны ±1, босс +1 (проверить крайние случаи), божественный уровень задаётся обменником. Миграция v55 сохраняет исходный JSON, XP, UID, прогресс и божественные параметры.

## Процедура
1. Зафиксируй версию, гипотезу, baseline и целевой диапазон, не придумывай результаты. Сравни одинаковые сборки и seed, волны 5/25/50/100/150/200.
2. Измерь время победы, вероятность провала, эффективное HP, DPS/HPS, доход/час, доступность лута. Проверяй соло, отряд 4, разный момент найма, повтор, дешёвые и сильные вещи.
3. Измени один связанный блок; объясни, почему. Для миграции тестируй повторную загрузку, полную сумку, невозможность backup.
4. `node tests/balance-equipment.mjs`, `node tests/balance-simulation.mjs`, `node tests/sanity.mjs`. Отдельно ручной плейтест. Результаты старого отчёта — исторические, не новые измерения.
