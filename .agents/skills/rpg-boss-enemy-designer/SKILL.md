# rpg-boss-enemy-designer

Следуй корневому AGENTS.md. Файлы ниже — точки входа, не обязательный список чтения. Документы без полного пути находятся в `docs/hordebreaker-devkit/`.


**Вход:** `config/monsters.js`, `config/levels.js`, `js/battle-skills.js`; `battle-base.js`/`battle.js` только для нужных эффектов.
1. Укажи стабильный ID, биом, роль, две способности (если соответствует существующей схеме), цель, порог HP, cooldown, предупреждение, контригру, лимит призыва. Сверь текущие профили и реальные имена полей.
2. Не копируй личность и набор старого босса; общие примитивы допустимы. Согласуй механику с автобоем и составами без лекаря/танка. Не создавай бесконечные циклы лечения/призыва.
3. Урон через канонические функции, визуальные эффекты отделены. Проверяй цель/смерть/смену волны, окончание эффектов, таймер босса, награду ровно один раз. Не меняй чужие механики и множители без задачи.
**Проверки:** `sanity.mjs`, `effects.mjs` при FX, `balance-simulation.mjs` при существенной смене сложности. Отчёт: таблица навыков и реальные сценарии теста.
