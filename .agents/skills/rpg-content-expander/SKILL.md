# rpg-content-expander

Следуй корневому AGENTS.md. Файлы ниже — точки входа, не обязательный список чтения. Документы без полного пути находятся в `docs/hordebreaker-devkit/`.


**Вход:** `GAME_DESIGN.md`, соответствующий `config/*.js`, точка использования в `js/` и тесты. `config/expansion.js` проверяй как есть, не предполагай готовый API.
1. Определи роль контента, стабильные ID, доступность, параметры, взаимодействия, UI, ассеты, сохранения и критерии готовности. Отдельно согласуй новые системы/баланс.
2. Переиспользуй существующие конфиги и функции. Не вводи новую зависимость ради контента. Для нового героя проверь найм, резерв, слот, порядок, атаки, навыки, звук и эффекты. Для предмета — классы, редкости, графику, лут, автоэкипировку.
3. Добавляй небольшим завершённым пакетом. Не называй контент готовым, если изображения, интеграция или проверки отсутствуют.
**Проверки:** `sanity.mjs`, `balance-equipment.mjs` для предметов/классов, `effects.mjs` для навыков, `browser.mjs` для UI. Отчёт: новые ID, правила, миграция/совместимость.
