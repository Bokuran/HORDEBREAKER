# rpg-combat-engineer

Следуй корневому AGENTS.md. Файлы ниже — точки входа, не обязательный список чтения. Документы без полного пути находятся в `docs/hordebreaker-devkit/`.


**Вход:** `js/battle.js`, `js/battle-base.js`, при навыках `js/battle-skills.js`; только при визуальной причине `battle-draw.js`, `battle-fx.js`.
1. Опиши воспроизведение: волна, состав, ширина, FPS, скорость, цель, состояние героя, ожидаемый и фактический урон. Проследи `bx.visibleEnemy`, `bx.rangedTarget`, контакт/размеры спрайтов и cooldown.
2. Дальники: Лучница, Маг, Некромант, Друид. Не заставляй их ждать контакта; не разрешай стрельбу по невидимой/мёртвой цели. Целители сохраняют приоритет осмысленного лечения. Ближники подходят к видимой цели без ложной границы арены.
3. Снаряд должен попадать при пересечении расстояния за шаг; не допускать двойного попадания, зависания, урона после смерти цели. Входящий урон через общую обработку, таймеры обновляются одним владельцем. FX не начисляют урон повторно.
4. Проверяй переход волны, повтор, боссов, отряд 1/4, 390/1900 px, ×1/×3 и 30/60/120 FPS где применимо.
**Проверки:** `sanity.mjs`, `formation.mjs`, `monster-contact.mjs`, `journey.mjs`, `effects.mjs` только затронутые. Фикс считается успешным по реальному HP/урону, не по анимации.
