# rpg-asset-art-director

Следуй корневому AGENTS.md. Файлы ниже — точки входа, не обязательный список чтения. Документы без полного пути находятся в `docs/hordebreaker-devkit/`.


**Вход:** `ART_GUIDE.md`, `config/heroes.js`, `config/monsters.js`, `config/levels.js` или `js/ui.js` (ICONS). Проверяй первичный `src`, не только наличие файла.
1. Инвентаризируй только требуемые ID, фактические форматы и размеры. Используй лучшие существующие WebP как референс; не заменяй их на упрощённый SVG. Генератор отсутствует — дай промпт и явный статус, не выдумывай результат.
2. Иконки 256×256, прозрачные, без текста, теней-подложек и двойной рамки. Враги: отдельный цельный силуэт, альфа, направление `face` согласно отрисовке. Панорамы: горизонтальная сцена, свободная земля, уникальная тема; без UI.
3. Сохрани ID, путь или обнови все ссылки; SVG fallback допустим. Не трогай гербы карты. При замене URL сохрани корректный cache bust. Исходные листы и предпросмотры не клади в runtime assets.
4. Проверь на контрастном фоне, на игровом размере, края, отсутствие соседних кропов и реальную загрузку. Обнови список ожидаемых файлов в sanity без ослабления проверок.
**Проверки:** `sanity.mjs`, `browser.mjs`; прозрачность/декодирование всех затронутых иконок, ручной скрин боя и инвентаря. Отчёт: сколько заменено/подключено, сколько ещё SVG, статус тестов.
