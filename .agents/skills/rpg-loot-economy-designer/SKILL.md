# rpg-loot-economy-designer

Следуй корневому AGENTS.md. Файлы ниже — точки входа, не обязательный список чтения. Документы без полного пути находятся в `docs/hordebreaker-devkit/`.


**Вход:** `config/items.js`, `js/core.js` (`T.items`, `T.derived`), `js/autoequip.js`; `js/ui.js` для отображения.
1. Проследи предмет от создания до экипировки/продажи. Проверки класса, слота, уровня и heavy — в ядре. UID принадлежит одному месту; резерв защищён; талисманы универсальны по классу.
2. Для автопродажи проверь режим off/spare/прочие реальные режимы, дроп и уже накопленную сумку. При spare предметы только для ненанятых классов могут продаваться по текущему правилу; сохраняй защиту экипированных, пригодных будущих вещей нанятых героев и recovery после миграции. Не продавай скрытно при снятии/замене/импорте.
3. Золото, алмазы и награды начисляются ровно один раз; переполнение не теряет чужую вещь. Учитывай все редкости, божественную экипировку, закалку, ограничение офлайн-награды и сохранение.
**Проверки:** `balance-equipment.mjs`, `sanity.mjs`; браузер при изменении UI. Сценарии: полная сумка, резерв, будущий уровень, нет подходящего класса, повторная загрузка, босс и офлайн.
