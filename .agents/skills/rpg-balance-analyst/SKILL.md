# rpg-balance-analyst

Следуй корневому AGENTS.md. Файлы ниже — точки входа, не обязательный список чтения. Документы без полного пути находятся в `docs/hordebreaker-devkit/`.


**Вход:** `config/balance.js`, `BALANCE_V55.md`, `docs/hordebreaker-devkit/BALANCE.md`; нужные формулы `js/core.js`, классы/предметы только по задаче.
1. Сними базовую линию из текущего кода, не из исторического README. Для гипотезы задай метрики, диапазоны волн, сборки и фиксированные seed.
2. Меняй минимальный набор коэффициентов, разделяй изменение XP/лут/экономика/враги. Сравни время победы, шанс успеха, DPS/HPS, EHP, доход/час, доступность предметов. Учитывай таймер босса, поход и повтор волн.
3. Не увеличивай уровень предмета или урон «на глаз». При изменении прогрессии определи судьбу старых вещей/XP и резервное копирование. Не пересчитывай божественные предметы без задачи.
**Проверки:** `balance-equipment.mjs`, `balance-simulation.mjs` с теми же условиями до/после, `sanity.mjs`. Симуляция контрольных сборок не доказывает баланс полного прохождения. Отчёт: до/после, условия, риск, оставшиеся тесты.
