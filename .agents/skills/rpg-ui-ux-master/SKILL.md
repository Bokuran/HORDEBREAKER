# rpg-ui-ux-master

Следуй корневому AGENTS.md. Файлы ниже — точки входа, не обязательный список чтения. Документы без полного пути находятся в `docs/hordebreaker-devkit/`.


**Вход:** `index.html`, `css/style.css`, `js/ui.js`; ядро только если UI обнаружил бизнес-ошибку.
1. Найди фактический DOM/рендерер, повторно используй существующие классы и переменные цветов. Тёмно-фиолетовый/золотой стиль, контраст, focus, hover, disabled. Нативные `select` и `option` должны оставаться читаемыми.
2. Четыре вкладки, вертикальная прокрутка, безопасные области мобильного экрана; не ломай ловушку фокуса и закрытие модалок. Один внешний обод редкости; прозрачные иконки без второй рамки.
3. Не переноси игровую валидацию только в UI. Сохрани доступность клавиатуры, прокрутку и работоспособность без мыши. Не меняй карту и игровой баланс по визуальной задаче.
**Проверки:** `browser.mjs`, 390 и ~1900 px, состояния disabled/выбранного пункта, реальные клики, отсутствие JS-ошибок. `sanity.mjs` при JS/HTML изменениях. Отчёт: скрин и что не проверено.
