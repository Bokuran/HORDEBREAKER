# rpg-level-world-builder

Следуй корневому AGENTS.md. Файлы ниже — точки входа, не обязательный список чтения. Документы без полного пути находятся в `docs/hordebreaker-devkit/`.


**Вход:** `config/levels.js`, `config/monsters.js`, `js/core.js` (`T.waves`), `js/battle.js`, `js/battle-base.js`; UI карты в `js/ui.js`.
1. Сверь существующие 20 зон и 200 волн первого похода, 2 обычных врага и 2 босса на зону. Не добавляй дубликаты и не меняй номер волны старых сохранений молча.
2. Для новой/изменённой зоны задай ID, диапазон, биом, врагов, босса, фон и `iconArt`. Гербы карты сохраняй, если пользователь не попросил их менять. Проверь относительные пути с учётом регистра Linux.
3. Проверь переход зоны, карту пройденного, повтор/отступление, финал и 5-секундный поход. Фон должен двигаться и не обрезать бой; не связывай игровой расчёт с визуальным декором.
**Проверки:** `sanity.mjs`, `journey.mjs`, `browser.mjs`. Отчёт: карта изменённых зон, ссылки на ассеты и проверенные волны.
